# Journey soundscape

Drop a royalty-free matchday crowd/ambience loop here named:

    matchday-soundscape.mp3

It plays during the Bus journey (crowd chatter, ambient voices, people
milling). The journey works fine without it — if the file is missing or the
browser blocks autoplay, the animation plays silently (see
`spec.md > Important Failure Modes`).

Good sources for free loops: Pixabay, Freesound (check the licence), or any
royalty-free SFX library. Keep it a seamless loop, ~20-40s.
